# Undead Afterdark Support

## Game support
Undead Afterdark is currently in active development.

For bugs, crashes, touch-control problems, multiplayer issues, or other support requests, open an issue in this repository and include:

- iPhone or iPad model
- iOS version
- game version shown on the title screen
- what you were doing when the problem happened
- whether you were playing solo or co-op

Repository issues:
https://github.com/ret906-boop/-undead-afterdark/issues

## Current supported play
- Solo survival
- Level 49 Endless
- Online co-op where available
- Landscape iPhone/iPad presentation

## Purchases
The current public build does not yet contain live App Store purchases. Purchase support information will be added before paid items are enabled.
